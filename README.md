# Student Grade Prediction

## Overview

This project uses Machine Learning to predict students' final grade (G3).

## Dataset

- 397 students
- 33 original features
- Target: G3

## Models

- Linear Regression
- Decision Tree
- Random Forest

## Preprocessing

- Numerical features
- One-Hot Encoding
- ColumnTransformer
- Pipeline

## Evaluation

- R²
- MAE
- MSE
- RMSE
- 5-Fold Cross-Validation

## Results

Random Forest:

- Test R²: 0.8911
- Mean CV R²: 0.8395
